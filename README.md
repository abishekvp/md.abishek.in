# Markdown Studio Pro — `md.abishek.in`

A professional, fullscreen, browser-based GitHub Flavored Markdown (GFM) workspace:
- **Dual Synchronized Panes:** Real-time dual split scrolling with Zen (Editor-only) and Reading (Preview-only) modes.
- **GFM Rendering:** Full support for tables, interactive task lists, footnotes, and custom styled code blocks with 1-click copy buttons.
- **KaTeX Mathematical Typesetting:** Live inline (`$...$`) and display (`$$...$$`) LaTeX math formulas.
- **Interactive Mermaid Diagrams:** Direct flowchart, sequence, and graph rendering into crisp vector SVGs.
- **Document Outline (TOC):** Dynamic Table of Contents sidebar for instant section jumping.
- **HTML ↔ Markdown Converter:** Bidirectional conversion between raw HTML and markdown.
- **Multi-Format Export:** Download `.md`, copy rendered HTML, export standalone styled HTML, and Print / Save as PDF.
